# SEVA SETU KENDRA

**Tagline:** Connecting Citizens with Government Opportunities

Complete WordPress platform bundle with custom theme + plugin.

## Included
- `wp-content/plugins/seva-setu-platform`: Roles, portals, agent onboarding, scheme/application CPTs, commission system, admin dashboard, AI finder.
- `wp-content/themes/seva-setu-theme`: Government-style responsive theme with core pages/navigation.
- `data/schemes-3000.csv`: 3000+ scheme rows for import.
- `docs/database-schema.md`: Data model reference.
- `docs/hostinger-deployment-guide.md`: End-to-end deployment steps.

## Quick Setup
1. Install WordPress.
2. Activate theme and plugin.
3. Create pages and assign shortcodes.
4. Import scheme dataset.
5. Review agent approvals from Users.

See `docs/hostinger-deployment-guide.md` for full production steps.
